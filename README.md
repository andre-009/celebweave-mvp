## 🎯 Overview

**CelebWeave** is a complete event planning and vendor marketplace platform designed specifically for Nigerian and African celebrations.

**What It Does:**
- Create events and manage guest lists
- Generate unique QR codes for each guest
- Scan QR codes at your event for instant check-in
- Coordinate Aso Ebi (traditional dress) selection and payments
- Discover and book 1,200+ trusted vendors
- Track attendance in real-time with analytics
- Send automated invitations and reminders

**Perfect For:** Weddings, Birthdays, Naming Ceremonies, Corporate Events, Engagements, Graduations

**Current Status:** MVP - Production Ready ✅

## 🚀 Quick Start

### **Option 1: View Locally (Fastest)**

1. Download/clone this repo
2. Double-click `celebweave-premium-full.html`
3. Boom! Website loads in your browser
4. No build step, no server needed

### **Option 2: Deploy to Vercel (Recommended)**

```bash
# 1. Push to GitHub
git init
git add .
git commit -m "CelebWeave MVP"
git remote add origin https://github.com/YOUR_USERNAME/celebweave.git
git branch -M main
git push -u origin main

# 2. Go to vercel.com → Import Project → Select GitHub repo
# 3. Deploy (takes 30 seconds)
# 4. Your site is live at: https://celebweave.vercel.app
```

### **Option 3: GitHub Pages (Free)**

```bash
# Push to main, then go to repo Settings → Pages
# Select "main" branch → Save
# Live at: https://YOUR_USERNAME.github.io/celebweave
```

## 🎯 Use Cases

### Wedding Planning
1. Create wedding event
2. Upload 120 guests via CSV
3. Auto-generate 120 unique QR codes
4. Send invitation emails with QR
5. At venue: scan each guest's QR as they arrive
6. See real-time dashboard: "85 checked in, 15 still arriving"
7. Get final report: "105 attended, 15 no-shows = 87% attendance"

### Corporate Gala (500 guests)
1. Create event
2. Import 500 attendee list
3. Generate QR codes
4. Scan at entrance (WebRTC camera)
5. Real-time attendance tracking
6. Export analytics for report

### Birthday Party (50 guests)
1. Add 50 guests manually
2. Generate & send QR codes
3. Scan at entrance
4. See who's arrived, who's late, who didn't show
